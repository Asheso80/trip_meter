How to use Trip Meter

A GPS cross-check for your meter and odometer. Not a legal-for-trade device.

Running a trip

  1. ACQUIRE GPS — warms up the signal. Wait while it counts fixes. The button unlocks once the signal is steady (5+ fixes, accuracy within 10 m).
  2. ZERO & START — clears any warm-up drift and starts the trip from a clean zero. Fare shows the $5.20 drop fee at once.
  3. Drive. Distance and fare climb live. PAUSE stops counting; RESUME re-acquires before continuing.
  4. RESET clears everything back to the start.

Why acquire first

Cold GPS scatters for the first several seconds and reads phantom distance while sitting still. Warming up then zeroing wipes that out, so your trip starts at a true zero.

Calibration (CAL)

Checks how accurate the GPS is against a distance you already know. Tap CAL, drive your measured 1.6 km stretch, and read the Error line. Green means within 3%. Run it a few times and average. You can leave CAL on during a real fare, but the error reading only means anything up to the 1.6 km mark.

Fixes

The number of good GPS readings accepted so far. A health indicator — if it climbs steadily, the signal is solid. It has no effect on the fare.

Fare

$5.20 to start, then $1.50 per kilometre. Exactly 1.6 km = $7.60.
